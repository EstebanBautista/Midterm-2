# Registro de la interacción con la IA

| Archivo | Qué es |
|---|---|
| `01_prompt_generacion.md` | Prompt exacto entregado a Claude Opus 5.5 (contexto limpio, sin acceso al repositorio) para generar la variante "IA directa" |
| `02_respuesta_ia.md` | Respuesta completa de la IA; su código se copió sin cambios a `src/ai.cpp` |
| `03_notas.md` | Resultado de compilar y probar el código generado (pasó todas las pruebas al primer intento) y observaciones técnicas |
| `04_propuestas_optimizacion.md` | Medición exploratoria y propuestas de optimización O1–O4 con sus riesgos |
| `05_decisiones_equipo.md` | Decisión del equipo sobre cada propuesta (se aplicaron O1 y O4) |

Las decisiones del equipo sobre las evaluaciones del artículo están en `entrega/decisiones_evaluacion.md`.
